# 更新日志（简体中文）

CHANGELOG.md 的中文版：标题与英文版相同，每项改动一行。未翻译的版本显示英文。

## 1.6.1.1 (2026-11-08)
- 基于 KintaroModding 及贡献者开发的 UE MM 1.6.1 修改，并改用自己的名称：影之刃模组管理器
- 粘贴 Nexus Mods 模组链接即可导入
- 启动时检查已导入模组的更新；可一键更新单个或全部模组，更新后保留原名称
- 设置中可填写 Nexus Mods API 密钥；免费账号在模组页面点击 Mod Manager Download 或 Slow download，文件会交给管理器下载
- 后台下载，右下角显示进度；下载完成后自动安装，并删除下载包
- 只有需要你选择时才弹出安装窗口
- 缺少 Mods Menu 或 PBZModLoader 时，报错下方会出现安装按钮
- 删除了捐赠和 Discord 按钮；程序更新改为来自本修改版的 GitHub Release

## 1.6.1 (2026-11-07)
- 模组行和详情中新增“打开模组页面”：适用于下载时保留模组网站原文件名的模组；程序从文件名中读取模组编号，无需联网
- 用旧版本安装的模组也会显示该链接；其他模组显示“无模组页面”，卡片上的模组两者都不显示
- 同一文件的第二次下载（文件名以 (1) 结尾）现在也能识别名称和版本
- 暂时无法实现真正的更新检查：这需要模组网站的 API 访问权限，相关申请仍在等待批准，因此“打开模组页面”是目前能做到的最大程度

## 1.6.0 (2026-11-07)
- Mods Menu 和 PBZModLoader 现在可以同时安装：Mods Menu 0.9.0 和 PBZModLoader 2.1.0 及更新版本可以同时运行
- 若已知任一方的旧版本会引发问题，会显示警告；PBZModLoader 的 hid 入口不会与 Mods Menu 同时使用
- “查看文件”会列出模组文件夹中非由管理器安装的文件
- UE4SS 窗口只在需要手动下载时才显示选择哪个版本的提示

## 1.5.9 (2026-11-07)
- 可按“全部”“已启用”“已禁用”筛选模组列表；“已启用”会隐藏已禁用的模组
- 列表现在还可按状态、类型和文件完整性排序，不只按名称和日期
- 标签输入框下方显示建议：你自己的标签和常用标签，输入时自动筛选；按 Tab 自动补全

## 1.5.8 (2026-11-07)
- 文件名与已安装的模组相同时，安装窗口会询问是更新它还是同时保留两者
- “保留两者”会将新模组放到 ~mods 中的单独文件夹，并提示可能只有一种样式生效
- Discord 按钮上方新增捐赠按钮：完全自愿，可用 X 永久移除（“关于”页面仍会保留）

## 1.5.7 (2026-11-06)
- 模组标签：安装时添加，或点击“添加标签”按钮，然后一键筛选列表
- 搜索框中的 X 可清除文字，按 Esc 也可以
- 游戏项目文件夹下的零散文件现在会完整安装，例如 Quest Navigation 的图片
- PBZModLoader 的模组也可从顶层没有 ProjectPBZ 文件夹的压缩包安装
- .sig 文件会随其 pak 一起安装；license.json、notice.ini 等文件不再被当作文档
- 模组可能需要的文件未被安装时，安装窗口会显示警告
- 安装窗口会提示只有 main.ts 的模组：PBZModLoader 2.0 无法使用它
- 下载内容中没有模组文件时，提示信息更清楚

## 1.5.6 (2026-11-05)
- 推荐卡片新增 PBZModLoader：自带 pak 模组修复，无需 UE4SS（感谢 LKF）
- UE4SS C++ BYPASS 作为额外下载保留在卡片上
- 可从手动安装的 PBZModLoader 升级：旧文件移到备份，模组和设置保留
- 可安装 PBZModLoader 的模组；压缩包含两个加载器的副本时只安装其中一个
- 脚本模组需等其加载器安装后才能安装
- Mods Menu 和 PBZModLoader 一次只能安装其中一个
- 仅与其他模组共用某个文件的模组不再替换那个模组
- 名为 install.js 或 notice.js 等的脚本不再被遗漏
- 安装“游戏文件”和“exe 目录文件”类型的模组前不再显示提示
- 安装问题始终显示在视野内；较长的文件说明会自动换行
