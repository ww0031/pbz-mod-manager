# 更新日誌（繁體中文）

CHANGELOG.md 的繁體中文版：標題與英文版相同，每項改動一行。未翻譯的版本顯示英文。

## 1.6.1.2 (2026-11-08)
- 安裝或更新時，模組資料夾中若有非管理器安裝的同名檔案（例如手動複製的模組），不再報錯阻止，而是先移到備份資料夾
- 下載的檔案會保留到模組安裝完成為止：取消安裝視窗或安裝失敗後，再按更新會直接安裝，不必重新下載

## 1.6.1.1 (2026-11-08)
- 基於 KintaroModding 及貢獻者開發的 UE MM 1.6.1 修改，並改用自己的名稱：影之刃模组管理器
- 貼上 Nexus Mods 模組連結即可匯入
- 啟動時檢查已匯入模組的更新；可一鍵更新單一或全部模組，更新後保留原名稱
- 設定中可填寫 Nexus Mods API 金鑰；免費帳號在模組頁面點擊 Mod Manager Download 或 Slow download，檔案會交給管理器下載
- 背景下載，右下角顯示進度；下載完成後自動安裝，並刪除下載包
- 只有需要你選擇時才彈出安裝視窗
- 缺少 Mods Menu 或 PBZModLoader 時，錯誤訊息下方會出現安裝按鈕
- 移除了贊助和 Discord 按鈕；程式更新改為來自本修改版的 GitHub Release

## 1.6.1 (2026-11-07)
- 模組列與詳細資料中新增「開啟模組頁面」：適用於下載時保留模組網站原始檔案名稱的模組；程式會從檔案名稱讀取模組編號，無需連網
- 以舊版本安裝的模組也會顯示此連結；其他模組會顯示「無模組頁面」，卡片上的模組兩者都不顯示
- 同一檔案的第二次下載（檔案名稱以 (1) 結尾）現在也能辨識名稱與版本
- 暫時無法實現真正的更新檢查：這需要模組網站的 API 存取權限，相關申請仍在等待核准，因此「開啟模組頁面」是目前能做到的最大程度

## 1.6.0 (2026-11-07)
- Mods Menu 和 PBZModLoader 現在可以同時安裝：Mods Menu 0.9.0 和 PBZModLoader 2.1.0 及更新版本可以同時執行
- 若已知任一方的舊版本會引發問題，會顯示警告；PBZModLoader 的 hid 入口不會與 Mods Menu 同時使用
- 「檢視檔案」會列出模組資料夾中非由管理器安裝的檔案
- UE4SS 視窗只在需要手動下載時才顯示選擇哪個版本的提示

## 1.5.9 (2026-11-07)
- 可依「全部」「已啟用」「已停用」篩選模組清單；「已啟用」會隱藏已停用的模組
- 清單現在也可依狀態、類型和檔案完整性排序，不只依名稱和日期
- 標籤輸入框下方顯示建議：你自己的標籤和常用標籤，輸入時自動篩選；按 Tab 自動完成

## 1.5.8 (2026-11-07)
- 檔案名稱與已安裝的模組相同時，安裝視窗會詢問是更新它還是同時保留兩者
- 「保留兩者」會將新模組放到 ~mods 中的獨立資料夾，並提示可能只有一種樣式生效
- Discord 按鈕上方新增贊助按鈕：完全自願，可用 X 永久移除（「關於」頁面仍會保留）

## 1.5.7 (2026-11-06)
- 模組標籤：安裝時新增，或點選「新增標籤」按鈕，然後一鍵篩選清單
- 搜尋框中的 X 可清除文字，按 Esc 也可以
- 遊戲專案資料夾下的零散檔案現在會完整安裝，例如 Quest Navigation 的圖片
- PBZModLoader 的模組也可從頂層沒有 ProjectPBZ 資料夾的壓縮檔安裝
- .sig 檔案會隨其 pak 一起安裝；license.json、notice.ini 等檔案不再被當作文件
- 模組可能需要的檔案未被安裝時，安裝視窗會顯示警告
- 安裝視窗會提示只有 main.ts 的模組：PBZModLoader 2.0 無法使用它
- 下載內容中沒有模組檔案時，提示訊息更清楚

## 1.5.6 (2026-11-05)
- 推薦卡片新增 PBZModLoader：內建 pak 模組修復，不需要 UE4SS（感謝 LKF）
- UE4SS C++ BYPASS 作為額外下載保留在卡片上
- 可從手動安裝的 PBZModLoader 升級：舊檔案移到備份，模組和設定保留
- 可安裝 PBZModLoader 的模組；壓縮檔含兩個載入器的副本時只安裝其中一個
- 腳本模組需等其載入器安裝後才能安裝
- Mods Menu 和 PBZModLoader 一次只能安裝其中一個
- 僅與其他模組共用某個檔案的模組不再取代那個模組
- 名為 install.js 或 notice.js 等的腳本不再被遺漏
- 安裝「遊戲檔案」和「exe 目錄檔案」類型的模組前不再顯示提示
- 安裝問題一律顯示在視野內；較長的檔案說明會自動換行
